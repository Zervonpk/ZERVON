      Projects Se Kaise Seekhein?

      Coding sirf padhne se nahi aati, banane se aati hai. Tutorial dekh kar samajh aa jata hai, lekin jab khud khali file se shuru karte ho tab asli seekhna hota hai. Is module mein hum teen projects banayenge aur har ek mein pichle modules ki skills use hongi.

      • Landing Page: HTML aur CSS (structure, layout, responsive).
      • Portfolio: HTML, CSS aur thora JavaScript.
      • Calculator: HTML, CSS aur JavaScript ki logic.
      SAB SE ZAROORI AADAT

      Code copy paste mat karo, har line khud type karo. Phir usme apni tarah se cheezein badlo: rang, text, layout. Ghalti hogi to Console (F12) mein error dekho. Ghaltiyon se hi seekhna hota hai.

      Project Ka Folder Structure

      Har project ek alag folder mein banao aur files ko saaf tareeqe se rakho. Isay VS Code mein File → Open Folder se kholo.

      STRUCTURE 
      my-project/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── images/

      Folder aur files ke naam chhote haroof (lowercase) mein rakho aur space ki jagah - use karo, jaise my-photo.jpg. Ye GitHub Pages par publish karte waqt masle se bachata hai.

      Step 3: JavaScript (js/script.js)

      JAVASCRIPT 
      const display = document.getElementById("display");
const buttons = document.querySelectorAll(".calc-btn");

let current = "0";       // jo number abhi screen par hai
let previous = null;     // pehla number
let operator = null;     // + - * /
let resetNext = false;   // agla number naye sire se shuru ho

function calculate(a, b, op) {
    switch (op) {
        case "+": return a + b;
        case "-": return a - b;
        case "*": return a * b;
        case "/": return b === 0 ? "Error" : a / b;
    }
}

function handleDigit(value) {
    if (current === "0" || resetNext) {
        current = value;
    } else {
        current += value;
    }
    resetNext = false;
}

function handleDot() {
    if (resetNext) {
        current = "0.";
        resetNext = false;
    } else if (!current.includes(".")) {
        current += ".";
    }
}

function handleOperator(value) {
    if (current === "Error") return;

    previous = parseFloat(current);
    operator = value;
    resetNext = true;
}

function handleEquals() {
    if (current === "Error" || operator === null || previous === null) return;

    const result = calculate(previous, parseFloat(current), operator);

    current = typeof result === "number"
        ? String(parseFloat(result.toFixed(10)))
        : result;

    previous = null;
    operator = null;
    resetNext = true;
}

function clearAll() {
    current = "0";
    previous = null;
    operator = null;
    resetNext = false;
}

buttons.forEach(button => {

    button.addEventListener("click", () => {

        const value = button.dataset.value;

        if (value === "C") {
            clearAll();
        } else if (value === "=") {
            handleEquals();
        } else if (value === ".") {
            handleDot();
        } else if ("+-*/".includes(value)) {
            handleOperator(value);
        } else {
            handleDigit(value);
        }

        display.textContent = current;

    });

});
      EHTIYAT

      Is code mein eval() use nahi kiya gaya. Ye function text ko code ki tarah chala deta hai aur security ke liye khatarnaak hai. Hamesha hisaab khud function se karo, jaisa upar calculate() mein kiya hai.

      Apna kaam: Backspace button add karo, keyboard se numbers likhne ka support do (keydown event), aur % ka button banao.

      Complete Responsive Website Ki Checklist

      Koi bhi project publish karne se pehle ye list check karo. Yehi cheezein ek amateur aur professional website mein farq banati hain.

      • Viewport meta tag lagi hui hai.
      • Website mobile, tablet aur laptop teeno par theek dikhti hai (Chrome mein F12 se test karo).
      • Kisi bhi screen par horizontal scroll (left-right) nahi aata.
      • Har image par alt likha hai aur max-width: 100% laga hai.
      • Har page ka apna title aur meta description hai.
      • Sirf ek h1 hai aur headings sahi order mein hain.
      • Saare links kaam karte hain (koi 404 nahi).
      • Buttons aur links par hover aur focus ka effect hai.
      • Text aur background ke rang mein itna farq hai ke asaani se padha jaye.
      • Console (F12) mein koi error nahi hai.
      YAAD RAKHO

      Pehla version perfect nahi hota. Pehle chalta hua banao, phir behtar karo. Har project ko publish karne ke baad dobara aa kar uski kamiyan theek karna hi developer ka asli safar hai.

      Is Module Ka Khulasa

      • Coding projects banane se seekhi jati hai, sirf padhne se nahi.
      • Har project ke liye saaf folder structure rakho.
      • Landing page HTML aur CSS (Grid, responsive) ka imtehaan hai.
      • Portfolio tumhari pehchan hai, isay hamesha update karte raho.
      • Calculator JavaScript ki logic aur events ka imtehaan hai.
      • Publish karne se pehle responsive checklist zaroor dekho.
