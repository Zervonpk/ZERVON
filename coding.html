      Programming Kya Hai?

      Programming ka matlab hai computer ko aisi instructions dena jin ko follow kar ke wo koi kaam kare. Jaise tum kisi ko recipe likh kar dete ho ke pehle ye karo, phir wo karo, waise hi programmer computer ko step-by-step instructions likh kar deta hai.

      In instructions ke set ko program kehte hain, aur ye instructions likhne ke amal ko coding kehte hain.

      REAL LIFE EXAMPLE

      Tum jab mobile par calculator app chalate ho, to koi programmer pehle se likh chuka hota hai ke "2 + 2" likhne par jawab "4" dikhana hai. Har app, website aur game isi tarah code se bana hota hai.

      Computer Instructions Kaise Samajhta Hai?

      Computer apne aap kuch nahi sochta. Wo sirf wohi karta hai jo usay bataya jaye, aur bilkul waise hi jaise bataya jaye. Is liye instructions saaf aur sahi order mein honi chahiye.

      • Computer ko exact instructions chahiye hoti hain.
      • Wo instructions ko upar se neeche ek ek kar ke chalata hai.
      • Agar instruction mein ghalti ho to wo ghalti wahi rehti hai jab tak tum theek na karo.

      Andar se computer sirf 0 aur 1 (binary) samajhta hai. Programming languages is liye bani hain ke hum insaano ki zubaan jaise code likh sakein aur computer usay khud binary mein badal le.

      Programming Languages

      Jaise insaan alag alag zubanein bolte hain, waise hi computer ke liye bhi bohot si programming languages hain. Har language ka apna kaam aur apni khasiyat hoti hai.

      • HTML: website ka structure banati hai.
      • CSS: website ko design aur styling deti hai.
      • JavaScript: website mein interactivity aur logic lati hai.
      • Python: automation, data aur AI ke liye mashhoor hai.
      HAMARA PATH

      Is course mein hum web development par focus karenge, is liye HTML, CSS aur JavaScript seekhenge.

      Algorithm Kya Hota Hai?

      Algorithm kisi masle ko hal karne ke steps ka list hota hai. Code likhne se pehle hum socha karte hain ke kaam kin steps mein hoga. Ye sochne ka tareeqa hi asal programming hai.

      Example: Chai Banane Ka Algorithm

      ALGORITHM 
      1. Pani garam karo
2. Pani mein chai ki patti dalo
3. Doodh aur cheeni daalo
4. 3 minute pakao
5. Cup mein chhan kar serve karo

      Dekho, har step clear hai aur sahi order mein hai. Computer ke liye bhi hum bilkul aisa hi plan banate hain, bas code ki zubaan mein.

      Tumhara Pehla Code

      Chalo ek chhota sa JavaScript code dekhte hain. Ye code screen par ek message dikhata hai.

      JAVASCRIPT 
      console.log("Hello, World!");
console.log("Main coding seekh raha hoon.");

      Yahan console.log() ek instruction hai jo brackets ke andar likha text screen (console) par dikhata hai. Computer ye dono lines upar se neeche ek ek kar ke chalayega.

      Coding Ke Basic Concepts

      Har programming language mein kuch common concepts hote hain. Inhein ek baar samajh liya to koi bhi language seekhna aasan ho jata hai.

      • Variables: data ko naam de kar store karna.
      • Conditions: faisla karna ke agar ye ho to wo karo (if / else).
      • Loops: ek kaam ko baar baar dohrana.
      • Functions: code ka ek hissa jo dobara dobara use ho sake.
      JAVASCRIPT 
      let age = 20;                      // variable

if (age >= 18) {                   // condition
    console.log("Tum adult ho.");
} else {
    console.log("Tum abhi minor ho.");
}

for (let i = 1; i <= 3; i++) {     // loop
    console.log("Number:", i);
}

      Is Module Ka Khulasa

      • Programming computer ko instructions dene ka amal hai.
      • Computer sirf wohi karta hai jo usay exact bataya jaye.
      • Programming languages insaan aur computer ke beech pul hain.
      • Algorithm pehle sochna hai, code baad mein likhna hai.
      • Variables, conditions, loops aur functions har language ki buniyad hain.
