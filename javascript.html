      JavaScript Kya Hai?

      JavaScript ek programming language hai jo website mein logic aur interactivity lati hai. Button par click karne se kuch hona, form check karna, menu kholna aur band karna, ye sab JavaScript se hota hai.

      TEEN LANGUAGES, TEEN KAAM

      HTML website ka dhancha banati hai, CSS usay sajati hai, aur JavaScript usay harkat deti hai. Ye teeno mil kar ek asli website banate hain.

      JavaScript browser ke andar chalti hai, is liye tumhein kuch install karne ki zaroorat nahi. Bas VS Code aur browser kaafi hai.

      JavaScript Ko HTML Mein Lagana

      CSS ki tarah JavaScript bhi alag file mein likhna behtar hai. js/script.js file banao aur HTML mein body band hone se pehle link karo.

      HTML 
      <body>

    <h1>Mera Page</h1>

    <script src="js/script.js"></script>

</body>

      Ya head mein defer ke sath bhi laga sakte ho. defer ka matlab hai ke pehle poora HTML load ho, phir script chale. Hamari website mein bhi yahi tareeqa use hua hai.

      HTML 
      <script src="js/script.js" defer></script>

      Code ka nateeja dekhne ke liye browser mein F12 dabao aur Console tab kholo. Wahan console.log() ka output aur errors nazar aate hain.

      Variables

      Variable ek dibba hai jis mein hum data rakhte hain aur usay naam dete hain, taake baad mein us naam se data dobara use kar sakein.

      JAVASCRIPT 
      let name = "Ali";          // badal sakte hain
const country = "Pakistan"; // kabhi nahi badalta

name = "Ahmed";            // theek hai
// country = "India";      // error aayega!

console.log(name, country);
      • let: jab value baad mein badalni ho.
      • const: jab value fix rahni ho. Zyadatar yahi use karo.
      • var: purana tareeqa hai, ab use na karo.
      NAAM RAKHNE KE QAWAID

      Naam mein space nahi hota aur wo number se shuru nahi ho sakta. JavaScript mein studentName jaisa style (camelCase) use hota hai. Naam aisa rakho jis se pata chale ke us mein kya hai.

      Data Types

      Har data ki ek qisam hoti hai. Sab se zaroori qismein:

      JAVASCRIPT 
      const text = "Salam";        // String (likhai)
const age = 20;               // Number (adad)
const price = 99.5;           // Number (decimal bhi)
const isStudent = true;       // Boolean (true ya false)
let empty = null;             // Null (jaan boojh kar khali)
let notSet;                   // Undefined (value di hi nahi gayi)

console.log(typeof text);     // "string"
console.log(typeof age);      // "number"
console.log(typeof isStudent); // "boolean"

      Strings ko jorne ke liye template literals (backticks) sab se aasan hain:

      JAVASCRIPT 
      const name = "Ali";
const age = 20;

console.log(`Mera naam ${name} hai aur meri umar ${age} saal hai.`);

      Operators

      JAVASCRIPT 
      // Hisaab ke operators
console.log(10 + 5);   // 15
console.log(10 - 5);   // 5
console.log(10 * 5);   // 50
console.log(10 / 5);   // 2
console.log(10 % 3);   // 1  (baqi bachne wala hissa)

// Muqabla karne wale operators
console.log(5 === 5);  // true  (value aur qisam dono barabar)
console.log(5 !== 3);  // true
console.log(5 > 3);    // true
console.log(5 <= 3);   // false

// Logical operators
console.log(true && false);  // false (dono true hon)
console.log(true || false);  // true  (koi ek true ho)
console.log(!true);          // false (ulta)
      EHTIYAT

      Muqabla karte waqt hamesha === use karo, == nahi. == qisam ko khud badal deta hai aur ajeeb nateeje de sakta hai.

      Conditions (If / Else)

      Conditions se program faisla karta hai ke kya karna hai.

      JAVASCRIPT 
      const marks = 72;

if (marks >= 80) {
    console.log("Grade A");
} else if (marks >= 60) {
    console.log("Grade B");
} else if (marks >= 40) {
    console.log("Grade C");
} else {
    console.log("Fail");
}

// Chhota tareeqa (ternary)
const result = marks >= 40 ? "Pass" : "Fail";
console.log(result);

      Upar wala code pehli sahi condition par ruk jata hai, baqi conditions check hi nahi hoti.

      Loops

      Loop ek kaam ko baar baar karta hai, taake tumhein wohi code dobara dobara na likhna parre.

      JAVASCRIPT 
      // for loop: 1 se 5 tak
for (let i = 1; i <= 5; i++) {
    console.log("Number:", i);
}

// while loop: jab tak condition sahi ho
let count = 3;
while (count > 0) {
    console.log("Countdown:", count);
    count--;
}
      • let i = 1: shuruaat.
      • i <= 5: jab tak ye sahi hai loop chalta rahe.
      • i++: har chakkar ke baad i ko 1 se barhao.
      EHTIYAT

      Agar loop ki condition kabhi galat na ho to wo hamesha chalta rahega (infinite loop) aur browser atak jayega. Hamesha dekho ke loop kahin na kahin khatam ho raha hai.

      Functions

      Function code ka ek naam wala hissa hai jo tum jitni baar chaho dobara use kar sakte ho. Isay ek machine samjho: kuch cheez andar daalo (parameters), wo kaam kare aur nateeja (return) wapas de.

      JAVASCRIPT 
      // Function banana
function greet(name) {
    return `Salam, ${name}!`;
}

console.log(greet("Ali"));    // Salam, Ali!
console.log(greet("Sara"));   // Salam, Sara!

// Arrow function (chhota tareeqa)
const add = (a, b) => a + b;

console.log(add(5, 3));       // 8

      Function ek baar likho, kai jagah use karo. Isi se code saaf aur chhota rehta hai.

      Arrays

      Array ek variable mein kai cheezein rakhne ka tareeqa hai. Har cheez ki ek position (index) hoti hai jo 0 se shuru hoti hai.

      JAVASCRIPT 
      const skills = ["HTML", "CSS", "JavaScript"];

console.log(skills[0]);       // HTML
console.log(skills.length);   // 3

skills.push("Git");           // aakhir mein add
skills.pop();                 // aakhri item hatao

// Har item par kaam karna
skills.forEach(skill => {
    console.log("Main seekh raha hoon:", skill);
});

// Naya array banana
const upper = skills.map(skill => skill.toUpperCase());
console.log(upper);           // ["HTML", "CSS", "JAVASCRIPT"]

// Filter karna
const long = skills.filter(skill => skill.length > 3);
console.log(long);            // ["HTML", "JavaScript"]

      Objects

      Object mein data naam: value ke jodon ki shakal mein hota hai. Kisi cheez ki puri maloomat ek jagah rakhne ke liye behtareen hai. Hamare app.js mein bhi har course ek object hai.

      JAVASCRIPT 
      const student = {
    name: "Ali",
    age: 20,
    skills: ["HTML", "CSS"],
    isActive: true
};

console.log(student.name);        // Ali
console.log(student["age"]);      // 20

student.age = 21;                 // badalna
student.city = "Multan";          // naya add karna

// Objects ka array (asli projects mein aam hai)
const courses = [
    { id: "html", title: "HTML Mastery" },
    { id: "css",  title: "CSS Mastery" }
];

console.log(courses[1].title);    // CSS Mastery

      DOM Manipulation

      DOM (Document Object Model) browser ka banaya hua HTML page ka woh roop hai jis ko JavaScript se badla ja sakta hai. Yahi wo jagah hai jahan JavaScript website ko zinda karti hai.

      Elements Chunna

      JAVASCRIPT 
      const title = document.getElementById("title");
const card = document.querySelector(".card");
const allCards = document.querySelectorAll(".card");

title.textContent = "Naya Heading";       // text badalna
title.style.color = "gold";               // style badalna
card.classList.add("active");             // class lagana
card.classList.remove("active");          // class hatana
card.classList.toggle("active");          // ho to hatao, na ho to lagao

      Naya Element Banana

      JAVASCRIPT 
      const list = document.getElementById("list");

const item = document.createElement("li");
item.textContent = "Naya item";

list.appendChild(item);
      EHTIYAT

      User ka likha hua text kabhi innerHTML mein mat daalo. Us mein chhupa hua code chal sakta hai jo website ko nuqsan pohancha sakta hai. User ke text ke liye textContent use karo.

      Events

      Event wo cheez hai jo page par hoti hai: click, typing, mouse ka upar aana. JavaScript in ka intezar karti hai aur jawab mein koi kaam karti hai.

      Ye pura chhota sa example hai jo HTML aur JavaScript ko milata hai. Pehle HTML:

      HTML 
      <h2 id="counter">0</h2>
<button id="plus">Barhao</button>
<button id="reset">Reset</button>

<script src="js/script.js"></script>

      Phir js/script.js mein:

      JAVASCRIPT 
      const counter = document.getElementById("counter");
const plusButton = document.getElementById("plus");
const resetButton = document.getElementById("reset");

let value = 0;

plusButton.addEventListener("click", () => {
    value++;
    counter.textContent = value;
});

resetButton.addEventListener("click", () => {
    value = 0;
    counter.textContent = value;
});

      Button dabane par number barhta hai. Ab tum samajh sakte ho ke hamari course website mein menu ka button, search box aur copy button kaise kaam karte hain: yehi cheezein hain.

      Is Module Ka Khulasa

      • JavaScript website mein interactivity aur logic lati hai.
      • const aur let se variables banate hain, var se bacho.
      • Muqabla karne ke liye === use karo.
      • Conditions faisla karti hain, loops kaam dohrate hain.
      • Functions code ko dobara use karne layak banate hain.
      • Arrays cheezon ki list aur objects maloomat ka set rakhte hain.
      • DOM aur events se JavaScript HTML page ko badalti hai.
      PRACTICE

      Ek chhota "To-Do List" banao: ek input box, ek "Add" button aur ek list. Button dabane par input ka text list mein naye item ki tarah add ho. Is mein variables, functions, DOM aur events sab aa jayenge. Agle module mein hum in sab se asli projects banayenge.
