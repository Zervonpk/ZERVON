Git & GitHub.

Git install karna, repository banana, commits aur branches samajhna, aur apna code GitHub par upload karna seekho. Har professional developer ke liye ye buniyadi skill hai.

4 Hours Beginner Roman Urdu

      Git Aur GitHub Kya Hain?

      Ye dono alag cheezein hain, aur log aksar inhein ek samajh lete hain.

      • Git: ek tool jo tumhare computer par chalta hai. Ye tumhare code ke har badlaav ko yaad rakhta hai.
      • GitHub: ek website jahan tum apna Git wala code online save aur share karte ho.
      MISAAL

      Git ko game ka "save point" samjho. Kuch bigar jaye to pichle save par wapas ja sakte ho. GitHub wo cloud hai jahan ye saare save points mehfooz rehte hain, aur dusre log bhi unhein dekh sakte hain.

      Git ke faide: code ki purani versions wapas mil jati hain, kai log ek hi project par saath kaam kar sakte hain, aur tumhara kaam online backup ho jata hai. GitHub par tumhara profile hi tumhara developer portfolio hota hai.

      Git Install Karna

      1. Browser mein git-scm.com kholo aur apne system ka version download karo.
      2. Installer chalao. Zyadatar options default rehne do aur har screen par Next dabate jao.
      3. Install hone ke baad VS Code ka terminal kholo (Ctrl + `).
      4. Check karo ke Git install hua ya nahi:
      TERMINAL 
      git --version

      Agar git version 2.xx.x jaisa kuch likh kar aaye to Git tayyar hai. Agar "not recognized" aaye to VS Code ko band kar ke dobara kholo.

      Pehli Baar Ki Setting

      Git har badlaav ke saath ye bhi likhta hai ke wo kis ne kiya. Is liye apna naam aur email ek baar bata do. Ye sirf ek dafa karna hota hai.

      TERMINAL 
      git config --global user.name "Tumhara Naam"
git config --global user.email "tumhari-email@example.com"
git config --global init.defaultBranch main
      ZAROORI

      Yahan wohi email likho jo tum GitHub account mein use karoge (ya jo GitHub ki settings mein tumhari email hai), taake commits tumhare account se jur jayein. Ye email commits mein public bhi nazar aa sakti hai, is liye GitHub ka diya hua private "noreply" email bhi use kar sakte ho.

      GitHub Account Banana

      1. github.com kholo aur Sign up dabao.
      2. Email, password aur username chuno.
      3. Email verify karo.
      4. Account security ke liye Two-factor authentication (2FA) zaroor on karo. Ye Settings → Password and authentication mein hota hai.
      USERNAME KA INTIKHAB

      Tumhara username tumhare GitHub link aur portfolio ka hissa banega (github.com/username), is liye professional aur saaf naam rakho. Jaise tumhara asli naam.

      Basic Concepts

      • Repository (repo): tumhare project ka folder jis ko Git track kar raha hai.
      • Commit: ek save point. Har commit ke saath ek chhota message hota hai ke kya badla.
      • Branch: code ki ek alag line jis par tum bina mukhya code bigaare naye tajurbe kar sakte ho.
      • Remote: repo ki online copy (GitHub par).
      • Push: apne commits GitHub par bhejna.
      • Pull: GitHub se naye badlaav apne computer par lana.
      • Clone: GitHub ke kisi repo ki poori copy apne computer par utarna.

      Git ka roz ka kaam ye hai: file mein badlaav karo, badlaav ko stage karo (commit ke liye chuno), commit karo, aur phir push karo.

      Pehla Repository Aur Commit

      VS Code mein apna project folder kholo, terminal kholo aur ye commands ek ek kar ke chalao:

      TERMINAL 
      git init                      # is folder ko Git repo banao
git status                    # dekho kya badla hai
git add .                     # saare badlaav stage karo
git commit -m "Pehla commit"  # save point banao
git log --oneline             # commits ki list dekho
      • git init: folder mein chhupa hua .git folder banata hai. Yahi tumhari history rakhta hai.
      • git status: ye sab se zyada kaam aane wala command hai, jab confuse ho to isay chalao.
      • git add .: current folder ke saare badlaav stage karta hai.
      • git commit -m "...": stage kiye hue badlaav ko message ke saath save karta hai.

      Achhe Commit Message Kaise Likhein

      Message mein batao ke kya badla, jaise "Navbar ka mobile menu theek kiya" ya "Contact form add kiya". "update" ya "asdf" jaise messages baad mein kisi kaam nahi aate.

      VS CODE KA TAREEQA

      Ye sab VS Code ke Source Control panel (left bar ka teesra icon, ya Ctrl + Shift + G) se bhi ho sakta hai. Wahan Initialize Repository dabao, files ke saamne + se stage karo, upar message likho aur Commit dabao. Lekin pehle commands seekho, is se samajh behtar hoti hai.

      Code GitHub Par Upload Karna

      Step 1: GitHub Par Khali Repo Banao

      1. GitHub mein login kar ke upar right ke + par click karo, phir New repository.
      2. Repository ka naam likho, jaise my-first-website.
      3. Public chuno (taake GitHub Pages par publish ho sake).
      4. README, .gitignore aur license ko tick mat karo (repo bilkul khali ho).
      5. Create repository dabao.

      Step 2: Apne Project Ko Us Se Jodo

      Banne ke baad GitHub tumhein ek link dikhayega. Apne terminal mein ye commands chalao (link apna lagana):

      TERMINAL 
      git branch -M main
git remote add origin https://github.com/USERNAME/my-first-website.git
git push -u origin main
      • git branch -M main: mukhya branch ka naam main kar deta hai.
      • git remote add origin ...: GitHub wale repo ko "origin" ke naam se jodta hai.
      • git push -u origin main: code GitHub par bhejta hai. -u sirf pehli dafa lagana hota hai.

      Login Kaise Hoga?

      Pehli dafa push karte waqt browser mein GitHub login ki window khulegi. Wahan sign in kar ke Authorize kar do. Ye Git ke saath aane wale Credential Manager se hota hai. GitHub ab account ka normal password terminal mein qabool nahi karta, is liye agar password maange to browser wala tareeqa ya Personal Access Token use karo (GitHub Settings → Developer settings mein banta hai).

      Push hone ke baad GitHub ka page refresh karo, tumhari saari files wahan nazar aayengi.

      Aage Ke Badlaav Kaise Bhejein

      TERMINAL 
      git add .
git commit -m "Footer ka design behtar kiya"
git push

      Ab har dafa bas yehi teen commands chalane hain.

      .gitignore Aur Secrets Ki Hifazat

      Kuch files GitHub par nahi jani chahiye, jaise passwords, API keys, ya bare faltu folders. Inhein chupane ke liye project ke main folder mein .gitignore naam ki file banao:

      .GITIGNORE 
      .env
node_modules/
.DS_Store
Thumbs.db
*.log
      BOHOT ZAROORI

      Public repo mein password, API key ya koi bhi secret kabhi mat daalo. Agar galti se chala jaye to sirf file hatana kaafi nahi, kyunke wo purani history mein rehti hai. Us key ko foran badal (revoke) do. Aur jo cheez chhupi rehni chahiye wo code mein likhni hi nahi chahiye.

      Branches

      Branch par tum naya feature alag se bana sakte ho. Ye theek na chale to main mein koi nuqsan nahi hota. Theek chale to usay main mein mila dete hain (merge).

      TERMINAL 
      git branch                  # saari branches dekho
git switch -c contact-form  # nayi branch banao aur us par jao

# ... yahan code badlo, add aur commit karo ...

git switch main             # wapas main par aao
git merge contact-form      # contact-form ka kaam main mein mila do
git branch -d contact-form  # kaam khatam, branch hata do

      Branch ko GitHub par bhejne ke liye git push -u origin contact-form chalao. Kai log ek saath kaam karte hain to har koi apni branch banata hai aur phir unhein milaya jata hai.

      Clone Aur Pull

      GitHub ka koi bhi project (apna ya kisi aur ka public) apne computer par utarne ke liye:

      TERMINAL 
      git clone https://github.com/USERNAME/my-first-website.git
cd my-first-website
code .

      Agar tum kisi aur computer par bhi kaam karte ho ya GitHub par koi badlaav hua hai, to apne computer ko update karne ke liye:

      TERMINAL 
      git pull
      TIP

      Kaam shuru karne se pehle git pull chalane ki aadat daalo, taake tum purani version par kaam na karo.

      Kaam Aane Wale Commands Aur Ghaltiyan

      TERMINAL 
      git status                    # abhi ki halat
git diff                      # kya badla hai (stage se pehle)
git log --oneline             # commits ki chhoti list
git restore file.html         # file ke na-commit hue badlaav wapas karo
git restore --staged file.html # stage ki hui file ko wapas hatao
      • "Author identity unknown" ka error: tumne naam aur email set nahi kiya, "Pehli Baar Ki Setting" wale hisse ke commands chalao.
      • "failed to push some refs": GitHub par kuch aisa hai jo tumhare paas nahi. Pehle git pull chalao, phir dobara push karo.
      • "not a git repository": tum us folder mein nahi ho jis mein git init chalaya tha. VS Code mein sahi folder kholo.
      • Commit ke baad file GitHub par nahi dikhi: commit ke baad git push bhi karna hota hai.
      EHTIYAT

      git restore file.html file ke na-commit hue badlaav hamesha ke liye mita deta hai. Isay chalane se pehle soch lo ke wo badlaav tumhein chahiye to nahi.

      Is Module Ka Khulasa

      • Git tumhare computer par code ka history rakhta hai, GitHub usay online save karta hai.
      • Roz ka kaam: git add ., git commit -m "...", git push.
      • Commit message mein saaf likho ke kya badla.
      • Passwords aur API keys kabhi GitHub par mat daalo, .gitignore use karo.
      • Branches mein naye tajurbe karo aur theek hone par main mein milao.
      • Kaam shuru karne se pehle git pull chalao.
      PRACTICE

      Pichle module ke kisi project (landing page ya portfolio) ke liye GitHub par repo banao aur code push karo. Phir ek chhota badlaav kar ke dobara commit aur push karo, aur GitHub par check karo ke history mein dono commits nazar aa rahe hain. Agle module mein hum isi repo ko GitHub Pages par live website bana kar duniya ke saath share karenge.
