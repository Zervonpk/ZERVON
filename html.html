      HTML Kya Hai?

      HTML ka full form HyperText Markup Language hai. Ye website ka dhancha (structure) banati hai. Heading kahan hogi, paragraph kahan hoga, image kahan lagegi, ye sab HTML se tay hota hai.

      Ye programming language nahi, markup language hai. Matlab ye logic nahi chalati, balke browser ko batati hai ke page par kya cheez kis tarah dikhani hai.

      MISAAL

      Ghar banate waqt pehle deewarein, darwaze aur kamray khare kiye jate hain. HTML wahi deewarein aur kamray hain. Rang aur sajawat baad mein CSS se ayegi.

      HTML Document Ka Structure

      Har HTML page ka ek basic dhancha hota hai. Isay yaad kar lo, har page mein yahi hoga:

      HTML 
      <!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mera Page</title>
</head>
<body>
    <h1>Hello, Developer!</h1>
</body>
</html>
      • <!DOCTYPE html>: browser ko batata hai ke ye modern HTML5 page hai.
      • <html>: poore page ka main container. lang="en" page ki zubaan batata hai.
      • <head>: page ki maloomat (title, encoding, CSS links). Ye screen par nahi dikhta.
      • <body>: wo sab kuch jo screen par nazar aata hai.
      TIP

      viewport wali meta line mobile par website sahi dikhane ke liye zaroori hai. Isay kabhi na bhoolna.

      Elements Aur Attributes

      HTML elements se banti hai. Ek element mein opening tag, content aur closing tag hota hai.

      HTML 
      <p>Ye ek paragraph hai.</p>

<!-- opening tag, content, closing tag -->

      Kuch elements ka closing tag nahi hota, jaise <img>, <br> aur <input>. Inhein void elements kehte hain.

      Attributes

      Attributes element ko extra maloomat dete hain. Ye hamesha opening tag ke andar naam="value" ki shakal mein likhe jate hain.

      HTML 
      <a href="https://example.com" target="_blank">Link</a>
<p id="intro" class="text-big">Intro paragraph</p>
      • id: element ka unique naam (ek page par ek hi baar).
      • class: elements ko group karne ka naam (CSS mein kaam aata hai).
      • href, src, alt: link, image ka raasta aur image ki tehreer.

      Headings, Paragraphs Aur Text

      HTML mein 6 level ki headings hoti hain. h1 sab se bari aur ahem, h6 sab se chhoti.

      HTML 
      <h1>Main Heading</h1>
<h2>Sub Heading</h2>
<h3>Chhoti Heading</h3>

<p>Ye ek <strong>zaroori</strong> aur <em>khaas</em> paragraph hai.</p>
<br>
<hr>
      • <p>: paragraph.
      • <strong>: bold aur ahem text.
      • <em>: italic aur zor dene wala text.
      • <br>: nayi line.
      • <hr>: horizontal lakeer.
      YAAD RAKHO

      Ek page par h1 sirf ek hi rakho aur headings ko sahi order mein likho. Heading sirf bara text banane ke liye mat use karo, ye search engines aur screen readers ke liye bhi zaroori hai.

      Links Aur Images

      Links

      HTML 
      <!-- doosri website ka link -->
<a href="https://www.google.com" target="_blank" rel="noopener">Google kholo</a>

<!-- apni website ke doosre page ka link -->
<a href="about.html">About Us</a>

<!-- usi page ke kisi hisse ka link -->
<a href="#contact">Neeche Contact par jao</a>

      target="_blank" link ko naye tab mein kholta hai. Iske sath rel="noopener" likhna security ke liye achhi aadat hai.

      Images

      HTML 
      <img src="images/photo.jpg" alt="Pahaar ke beech jheel" width="400">
      • src: image ki file ka raasta.
      • alt: image ki tehreer. Image na khule ya screen reader use ho to ye kaam aata hai.
      • width / height: image ka size.

      Lists

      Cheezon ki fehrist banane ke liye lists use hoti hain. Do qisam ki lists sab se zyada kaam aati hain.

      HTML 
      <!-- Unordered list (bullets) -->
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

<!-- Ordered list (numbers) -->
<ol>
    <li>VS Code install karo</li>
    <li>Folder banao</li>
    <li>Code likho</li>
</ol>

      ul unordered list hai (bullets wali) aur ol ordered list (numbers wali). Dono mein har item li ke andar likha jata hai.

      Tables

      Data ko rows aur columns mein dikhane ke liye table use hota hai.

      HTML 
      <table border="1">
    <thead>
        <tr>
            <th>Course</th>
            <th>Duration</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>HTML</td>
            <td>8 Hours</td>
        </tr>
        <tr>
            <td>CSS</td>
            <td>10 Hours</td>
        </tr>
    </tbody>
</table>
      • <tr>: ek row.
      • <th>: heading wala cell.
      • <td>: data wala cell.
      • <thead> aur <tbody>: table ko hisson mein baantte hain.
      EHTIYAT

      Table sirf data dikhane ke liye use karo, page ka layout banane ke liye nahi. Layout CSS se banta hai.

      Forms

      Forms se website user se maloomat leti hai, jaise naam, email ya message. Ek simple contact form dekho:

      HTML 
      <form action="#" method="post">

    <label for="name">Naam</label>
    <input type="text" id="name" name="name" required>

    <label for="email">Email</label>
    <input type="email" id="email" name="email" required>

    <label for="level">Level</label>
    <select id="level" name="level">
        <option value="beginner">Beginner</option>
        <option value="intermediate">Intermediate</option>
    </select>

    <label for="message">Message</label>
    <textarea id="message" name="message" rows="4"></textarea>

    <button type="submit">Bhejo</button>

</form>
      • <label>: input ka naam. for ki value input ki id se milni chahiye.
      • type: input ki qisam (text, email, password, number, checkbox waghera).
      • required: khaali chhorne par browser khud rok deta hai.
      • name: data ko pehchanne ke liye zaroori hai.

      Ye form sirf screen par dikhta hai. Data kahan jayega aur kaise save hoga, ye JavaScript ya kisi server se hota hai, jo hum aage seekhenge.

      Semantic HTML

      Semantic ka matlab hai aise tags jin ke naam se hi unka matlab pata chal jaye. Har cheez ke liye <div> likhne ke bajaye mukhtalif hisson ke liye sahi tag use karte hain.

      HTML 
      <header>
    <nav>Menu yahan</nav>
</header>

<main>
    <section>
        <h2>Hamare Courses</h2>
        <article>Ek course ki detail</article>
    </section>

    <aside>Side ki maloomat</aside>
</main>

<footer>Page ka akhri hissa</footer>
      • <header>: page ya section ka upar wala hissa.
      • <nav>: navigation links.
      • <main>: page ka asal content (ek page par ek hi).
      • <section>: mauzu ke hisaab se alag hissa.
      • <article>: aisa content jo akela bhi samajh aaye.
      • <footer>: page ya section ka neeche wala hissa.

      Semantic HTML se code saaf padhne ko milta hai, search engines (SEO) website ko behtar samajhte hain, aur visually impaired logon ke liye screen readers bhi sahi kaam karte hain.

      Is Module Ka Khulasa

      • HTML website ka structure banati hai, design nahi.
      • Har page mein doctype, html, head aur body hota hai.
      • Elements tags se bante hain aur attributes unhein extra maloomat dete hain.
      • Links a, images img, lists ul/ol aur data table se banta hai.
      • Forms user se input lene ke liye hain.
      • Semantic tags page ko saaf, SEO-friendly aur accessible banate hain.
      PRACTICE

      Apna ek "About Me" page banao jis mein heading, apni photo, apne shaunq ki list, ek chhota table aur ek contact form ho. Sab semantic tags ke sath likho. Agle module mein hum CSS se isay khoobsurat banayenge.
