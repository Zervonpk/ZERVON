Website Deployment.

GitHub Pages par apni website free mein publish karo, live URL hasil karo aur apna kaam duniya ke saath share karo. Yahan tumhara pura safar mukammal hota hai.

3 Hours Beginner Roman Urdu

COURSE MODULES

    ON THIS PAGE

      Deployment Kya Hota Hai?

      Abhi tumhari website sirf tumhare computer par chalti hai. Deployment (publishing) ka matlab hai usay internet par rakhna taake koi bhi, kisi bhi jagah se, ek link se usay khol sake.

      Is ke liye website ko ek server par rakhna parta hai, jo hamesha internet se judaa rehta hai. Is service ko hosting kehte hain.

      GITHUB PAGES KYUN?

      GitHub Pages ek free hosting service hai jo seedha tumhare GitHub repo se website chala deti hai. Ye HTML, CSS aur JavaScript wali static websites ke liye bani hai, jaisi hum is course mein bana rahe hain. Is mein kisi alag server ya backend ki zaroorat nahi parti.

      Is ki hadd ye hai ke ye sirf static files chalati hai. Login, database ya payment jaisi cheezein jinhein server par code chalana parta hai, wo is par nahi chalti.

      Publish Karne Se Pehle

      Pichle module mein tumne apna project GitHub par push kar liya tha. Ab ye cheezein check karo:

      • Repository Public hai. GitHub ke free account par Pages sirf public repo ke liye milta hai.
      • Main file ka naam bilkul index.html hai (chhote haroof mein) aur wo repo ke sab se bahar wale hisse (root) mein hai, kisi folder ke andar nahi.
      • Saare links aur file paths relative hain.
      • Website tumhare computer par Live Server se theek chal rahi hai.
      RELATIVE PATHS KI AHEMIYAT

      Ye likho: css/style.css ya ../index.html. Ye mat likho: /css/style.css (shuru mein / ke saath) ya C:/Users/.... GitHub Pages par tumhari website ek folder jaisi jagah (username.github.io/repo-name/) mein hoti hai, is liye / se shuru hone wale raaste galat jagah dhoondhte hain aur CSS aur images load nahi hoti.

      GitHub Pages Par Website Live Karna

      1. GitHub par apna repository kholo.
      2. Upar wale menu mein Settings par click karo.
      3. Left sidebar mein Pages chuno.
      4. Build and deployment ke neeche Source mein Deploy from a branch chuno.
      5. Branch mein main aur folder mein / (root) chuno.
      6. Save dabao.
      7. Ek ya do minute intezar karo aur page refresh karo.

      Page ke upar ek message aayega jis mein tumhari website ka link hoga. Is ki shakal ye hogi:

      URL 
      https://USERNAME.github.io/REPOSITORY-NAME/

      Mubarak ho, tumhari website live hai! Ye link kisi ko bhi bhej do, wo apne mobile ya computer par khol lega.

      PEHLI DAFA INTEZAR

      Pehli dafa publish hone mein kuch minute lag sakte hain. Repo ke Actions tab mein tum dekh sakte ho ke deployment chal rahi hai ya mukammal ho chuki hai. Jab wahan hara (green) nishan aa jaye to link kaam karega.

      Website Ko Update Karna

      Koi badlaav karna ho to wohi teen commands jo tumne pichle module mein seekhi hain:

      TERMINAL 
      git add .
git commit -m "Contact section ka text theek kiya"
git push

      Push karte hi GitHub khud naya version publish kar deta hai. Is mein ek do minute lag sakte hain. Agar browser mein purani website nazar aaye to Ctrl + Shift + R daba kar page ko dobara zabardasti load karo.

      Apni Pehchan Wali Website (username.github.io)

      Upar wale tareeqe se link mein repo ka naam bhi aata hai. Agar tum chaho ke tumhari main portfolio ka link sirf username.github.io ho, to ek khaas naam ka repo banao:

      REPO KA NAAM 
      USERNAME.github.io

      Yahan USERNAME ki jagah apna GitHub username likho (bilkul wahi spelling). Is repo mein portfolio ki files rakho aur upar wale steps se Pages on kar do. Link ban jayega: https://USERNAME.github.io/. Har account ka ek aisa hi portfolio repo ho sakta hai, aur baqi projects ke apne alag links rehte hain.

      Apna Domain (Optional)

      Agar tum github.io ki jagah apna naam (jaise zervon.com) lagana chaho to domain kisi domain seller se kharidna parta hai (ye free nahi hota, saalana qeemat hoti hai). Phir:

      1. GitHub ke Settings → Pages mein Custom domain ke box mein apna domain likh kar Save karo.
      2. Domain seller ke DNS settings mein GitHub ki hidayat ke mutabiq records add karo (GitHub ka documentation us waqt ki sahi values batata hai).
      3. DNS ke update hone ka intezar karo (kuch minute se kuch ghantay).
      4. Pages ki settings mein Enforce HTTPS tick karo.
      PEHLE SEEKHO

      Shuru mein free github.io link se hi kaam chalao. Domain tab lo jab tumhara portfolio ya project tayyar ho aur tum usay seriously share karna chaho.

      Masle Aur Unke Hal

      • Link kholne par 404 (page not found) aata hai: check karo ke file ka naam index.html hai (index.htm ya Index.html nahi) aur wo repo ke root mein hai. Pages settings mein sahi branch aur / (root) chuna hua hai ya nahi, ye bhi dekho.
      • Website khul gayi lekin design nahi hai: CSS file ka raasta galat hai. Raaste / se shuru to nahi? Aur folder ya file ke naam ke haroof (chhote ya bare) bilkul sahi hain?
      • Computer par chal rahi thi, online par images nahi aati: GitHub Pages haroof ke chhote bare hone (case) par sakhti karta hai. Images/Photo.JPG aur images/photo.jpg alag samjhe jate hain. Windows is farq ko nazar andaz kar deta hai, is liye wahan masla nazar nahi aata.
      • Badlaav push kiya lekin website purani hai: Actions tab mein dekho deployment mukammal hui ya nahi, thora intezar karo, phir Ctrl + Shift + R se dobara load karo.
      • Pages ka option nazar nahi aata ya disabled hai: repo private to nahi? Free account par Pages ke liye repo public hona chahiye.

      Kisi bhi masle mein browser ka Console (F12) kholo. Wahan laal rang mein likha hota hai ke kaunsi file nahi mil rahi, aur usi se masla pakar mein aa jata hai.

      Apna 404 Page

      Agar koi galat link khole to GitHub Pages ek saada sa page dikhata hai. Repo ke root mein 404.html naam ki file bana do, GitHub Pages ghalat link par wahi dikhayega.

      HTML 
      <!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Page Nahi Mila</title>
</head>
<body>
    <h1>404</h1>
    <p>Ye page mojood nahi hai.</p>
    <a href="index.html">Home par wapas jao</a>
</body>
</html>
      NOTE

      Project ke URL (username.github.io/repo/) par ghalat link ke liye 404 page mein href ko relative rakho aur CSS ka link bhi isi tarah likho, warna wo us waqt load nahi hoga.

      Share Karne Se Pehle Ki Checklist

      • Live link tumhare mobile aur kisi doosre device par khol kar dekha hai.
      • Saare pages aur links kaam karte hain.
      • Console (F12) mein koi error nahi.
      • Repo mein koi password, API key ya personal maloomat nahi.
      • Repo ki description mein website ka link likha hua hai (repo ke upar About ke paas edit se).
      • Repo mein ek README.md hai jis mein project ka chhota taaruf aur live link hai.
      APNA KAAM DIKHAO

      Live link apne dosto, family aur social media par share karo, aur apne GitHub profile par pin kar do. Ye tumhara asli portfolio hai jo clients aur companies ko tumhari skills dikhata hai.

      Course Ka Khulasa

      • Deployment website ko internet par rakhna hai taake sab dekh sakein.
      • GitHub Pages static websites ke liye free hosting hai.
      • Repo public ho, index.html root mein ho aur raaste relative hon.
      • Settings → Pages mein main branch aur / (root) chuno.
      • Update ke liye bas add, commit aur push.
      • Masle aaye to 404, raaste, haroof ke farq aur Console dekho.
      AB TUMHARI BAARI

      Tumne VS Code seekha, HTML, CSS aur JavaScript seekhi, projects banaye, Git aur GitHub use kiya aur ab website live bhi kar sakte ho. Apna pehla project publish karo, uska link share karo, aur seekhna kabhi band mat karo. Har naya project tumhein behtar developer banata hai.
