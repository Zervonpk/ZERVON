      CSS Kya Hai?

      CSS ka full form Cascading Style Sheets hai. HTML website ka dhancha banati hai, aur CSS us dhanche ko rang, size, spacing aur layout deti hai.

      MISAAL

      Agar HTML ghar ki deewarein hain, to CSS us ka rang, farsh, furniture ki jagah aur sajawat hai. Wohi HTML CSS ke sath bilkul alag nazar aati hai.

      CSS ka basic tareeqa ye hai: pehle batao kis element par asar dalna hai (selector), phir batao kya badalna hai (property aur value).

      CSS 
      h1 {
    color: gold;
    font-size: 40px;
}

/* h1       = selector
   color    = property
   gold     = value */

      CSS Ko HTML Mein Kaise Lagayein?

      CSS lagane ke teen tareeqe hain. Professional projects mein hamesha pehla tareeqa use hota hai.

      1. External CSS (sab se behtar)

      Alag style.css file banao aur HTML ke head mein link kar do. Ek file se poori website ka design control hota hai.

      HTML 
      <head>
    <link rel="stylesheet" href="css/style.css">
</head>

      2. Internal CSS

      HTML 
      <style>
    p { color: gray; }
</style>

      3. Inline CSS

      HTML 
      <p style="color: red;">Ye text laal hai</p>
      TIP

      Inline CSS sirf bohot chhoti testing ke liye theek hai. Asli projects mein external CSS hi use karo, is se code saaf rehta hai aur dobara dobara likhna nahi parta.

      Selectors

      Selector batata hai ke CSS kis element par lagegi. Ye CSS ka sab se zaroori hissa hai.

      CSS 
      /* Element selector: sab paragraphs */
p { color: gray; }

/* Class selector: class="card" wale */
.card { padding: 20px; }

/* ID selector: id="logo" wala */
#logo { font-size: 30px; }

/* Descendant: card ke andar ke sab p */
.card p { margin: 0; }

/* Child: sirf seedhe bachay */
ul > li { list-style: none; }

/* Group: kai selectors ek sath */
h1, h2, h3 { font-family: sans-serif; }

/* Pseudo-class: mouse upar aaye to */
a:hover { color: gold; }
      • .naam class ke liye (dot lagta hai). Ye sab se zyada use hota hai.
      • #naam id ke liye (hash lagta hai). Ek page par ek hi baar.
      • :hover, :focus special states ke liye hain.
      YAAD RAKHO

      Agar do rules aapas mein takraein to jo zyada specific ho wo jeet'ta hai (id class se taqatwar, class element se taqatwar). Barabar hone par file mein jo baad mein likha ho wo lagta hai.

      Colors Aur Typography

      Colors

      CSS mein colors kai tareeqon se likhe ja sakte hain:

      CSS 
      .box {
    color: red;                           /* naam */
    background: #d8b477;                  /* hex code */
    border-color: rgb(216, 180, 119);     /* rgb */
    box-shadow: 0 4px 20px rgba(0,0,0,0.3); /* rgba: transparency ke sath */
}

      Typography

      CSS 
      body {
    font-family: 'DM Sans', sans-serif;
    font-size: 16px;
    font-weight: 400;
    line-height: 1.6;
    letter-spacing: 0.5px;
    text-align: left;
    text-transform: none;
}

      font-family mein hamesha aakhir mein sans-serif jaisa backup font likho, taake pehla font load na ho to bhi page theek dikhe. line-height: 1.6 paragraph ko padhne mein aasan banata hai.

      Box Model

      HTML ka har element ek dibbe (box) ki tarah hota hai. Is dibbe ke 4 hisse hain, andar se bahar:

      • Content: asal text ya image.
      • Padding: content ke gird andar ki khali jagah.
      • Border: dibbe ki lakeer.
      • Margin: dibbe ke bahar doosre elements se faasla.
      CSS 
      * {
    box-sizing: border-box;   /* padding aur border width ke andar hi ginti hon */
}

.card {
    width: 300px;
    padding: 20px;            /* chaaron taraf 20px */
    border: 1px solid #333;
    margin: 0 auto 30px;      /* upar 0, left-right auto (beech mein), neeche 30px */
}
      TIP

      box-sizing: border-box har project ki shuruat mein laga do. Is se sizes ka hisaab bohot aasan ho jata hai.

      Display Aur Position

      Display

      • block: poori line leta hai (div, p, h1).
      • inline: sirf utni jagah leta hai jitni zaroori ho (span, a).
      • inline-block: line mein rehta hai lekin width aur height le sakta hai.
      • none: element ko chhupa deta hai.

      Position

      CSS 
      .parent {
    position: relative;      /* bachon ka reference point */
}

.badge {
    position: absolute;      /* parent ke hisaab se jagah */
    top: 10px;
    right: 10px;
}

.navbar {
    position: sticky;        /* scroll par upar chipak jata hai */
    top: 0;
}

.chat-button {
    position: fixed;         /* screen par hamesha ek hi jagah */
    bottom: 20px;
    right: 20px;
}

      Flexbox

      Flexbox elements ko ek line (row) ya ek column mein saaf tareeqe se arrange karne ke liye hai. Navbar, buttons ki qatar aur cards ke liye perfect hai.

      CSS 
      .navbar {
    display: flex;                   /* flexbox shuru */
    justify-content: space-between;  /* main direction mein jagah */
    align-items: center;             /* doosri direction mein beech mein */
    gap: 20px;                       /* elements ke beech faasla */
}

.column-layout {
    display: flex;
    flex-direction: column;          /* upar se neeche */
    flex-wrap: wrap;                 /* jagah kam ho to agli line par */
}
      • justify-content: elements ko main direction (row mein left-right) mein baantta hai.
      • align-items: doosri direction (row mein upar-neeche) mein align karta hai.
      • gap: items ke beech ka faasla.

      CSS Grid

      Grid rows aur columns dono mein layout banane ke liye hai. Cards ki gallery ya poore page ka dhancha banane ke liye behtareen hai.

      CSS 
      .cards {
    display: grid;
    grid-template-columns: repeat(3, 1fr);   /* 3 barabar columns */
    gap: 20px;
}

/* Khud-ba-khud adjust hone wala grid */
.auto-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 20px;
}
      FARQ

      Flexbox ek direction (ek line ya ek column) ke liye hai. Grid do direction (rows aur columns) ke liye. Aksar dono ek hi project mein saath use hote hain.

      Transitions Aur Animations

      Transition

      Transition kisi cheez ko ek halat se doosri halat mein narmi se badalta hai, jaise mouse upar lane par button ka rang.

      CSS 
      .button {
    background: #d8b477;
    transition: all 0.3s ease;
}

.button:hover {
    background: #f4d6a0;
    transform: translateY(-4px);
}

      Animation

      CSS 
      @keyframes fadeUp {
    from {
        opacity: 0;
        transform: translateY(25px);
    }
    to {
        opacity: 1;
        transform: translateY(0);
    }
}

.hero {
    animation: fadeUp 0.8s ease both;
}

      Animation ko bohot zyada mat bharo. Halki aur maqsad wali animations website ko professional dikhati hain.

      Responsive Design

      Aaj zyadatar log website mobile par dekhte hain. Responsive design ka matlab hai ke website har screen (mobile, tablet, laptop) par theek dikhe.

      1. HTML mein viewport meta tag lagao (pichle module mein seekha).
      2. Fixed pixel ki jagah %, rem, max-width use karo.
      3. Media queries se alag screen size ke liye alag CSS likho.
      CSS 
      img {
    max-width: 100%;     /* image screen se bahar na jaye */
    height: auto;
}

.cards {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

/* Tablet: 2 columns */
@media (max-width: 1050px) {
    .cards { grid-template-columns: repeat(2, 1fr); }
}

/* Mobile: 1 column */
@media (max-width: 760px) {
    .cards { grid-template-columns: 1fr; }
}
      TIP

      Apni website ko Chrome mein F12 daba kar mobile mode (device toolbar) mein test karo. Chhoti screen se shuru kar ke bari screen ke liye design karna (mobile-first) bhi ek achha tareeqa hai.

      Is Module Ka Khulasa

      • CSS HTML ko rang, spacing aur layout deti hai.
      • Hamesha external style.css file use karo.
      • Selectors (element, class, id) batate hain CSS kis par lagegi.
      • Box model: content, padding, border aur margin.
      • Flexbox ek direction ke liye, Grid rows aur columns dono ke liye.
      • Transitions aur animations website ko zinda banate hain.
      • Media queries website ko har screen par theek dikhate hain.
      PRACTICE

      Pichle module mein jo "About Me" page banaya tha usay style.css se design karo: ek navbar (Flexbox), cards ki gallery (Grid), hover effects aur mobile ke liye media query. Agla module JavaScript ka hai jahan page mein jaan aayegi.
