      VS Code Kya Hai?

      Visual Studio Code (VS Code) ek free code editor hai jo Microsoft ne banaya hai. Isme hum code likhte hain, files manage karte hain aur apne projects chalate hain. Aaj duniya ke zyadatar web developers isi ko use karte hain.

      Tum Notepad mein bhi code likh sakte ho, lekin VS Code tumhein colors, auto-complete, error ki nishandahi aur bohot si tools deta hai jis se coding tez aur aasan ho jati hai.

      YAAD RAKHO

      VS Code aur Visual Studio dono alag cheezein hain. Hum yahan sirf Visual Studio Code (neela icon) install karenge.

      VS Code Install Karna

      1. Browser mein code.visualstudio.com kholo.
      2. Apne system ke hisaab se Download button dabao (Windows, Mac ya Linux).
      3. Downloaded file chalao aur installation shuru karo.
      4. Windows par "Select Additional Tasks" screen par ye options zaroor tick karo:
        • Add "Open with Code" action to Windows Explorer file context menu
        • Add "Open with Code" action to Windows Explorer directory context menu
        • Add to PATH
      5. Install complete hone par VS Code open karo.
      TIP

      "Open with Code" option tick karne se kisi bhi folder par right-click kar ke seedha VS Code mein khol sakte ho.

      VS Code Ka Interface

      VS Code kholte hi tumhein kuch hisse nazar aayenge. Inhein pehchan lo, bar bar kaam aayenge.

      • Activity Bar (left ki patti): Explorer, Search, Source Control aur Extensions ke icons.
      • Explorer: tumhare project ki files aur folders yahan dikhte hain.
      • Editor: beech ka bara hissa jahan tum code likhte ho.
      • Terminal (neeche): commands chalane ki jagah.
      • Status Bar (sab se neeche): file ki language aur line number jaisi maloomat.

      Zaroori Shortcuts

      • Ctrl + S: file save karna
      • Ctrl + Shift + X: extensions kholna
      • Ctrl + `: terminal kholna ya band karna
      • Ctrl + ,: settings kholna
      • Ctrl + Shift + P: command palette (har command yahan se chalta hai)
      • Ctrl + /: line ko comment karna

      Mac par Ctrl ki jagah Cmd use karo.

      Zaroori Extensions

      Extensions VS Code mein nayi khasiyatein add karte hain. Ctrl + Shift + X dabao, search box mein naam likho aur Install dabao. Shuru ke liye ye teen kaafi hain:

      • Live Server: website ko browser mein chalata hai aur file save karte hi page khud refresh ho jata hai.
      • Prettier - Code formatter: code ko khud saaf aur sahi tareeqe se arrange karta hai.
      • Material Icon Theme: files ke liye khoobsurat icons deta hai (zaroori nahi, lekin achha lagta hai).
      EHTIYAT

      Bohot zyada extensions install mat karo, VS Code sust ho sakta hai. Sirf wohi lo jinki zaroorat ho, aur install karne se pehle publisher ka naam aur downloads ki tadaad zaroor dekho.

      Themes Aur Settings

      Theme VS Code ke colors badalti hai. Ctrl + K dabao, phir Ctrl + T, aur list mein se koi bhi theme chuno. Dark themes aankhon ke liye aasan hoti hain.

      Behtareen Settings

      Ctrl + Shift + P dabao, "Open User Settings (JSON)" likho aur Enter dabao. Phir ye settings add karo (pehle se likhi cheezein na mitao, sirf in lines ko curly brackets ke andar daalo):

      JSON 
      "editor.fontSize": 16,
"editor.wordWrap": "on",
"editor.formatOnSave": true,
"files.autoSave": "afterDelay"
      • fontSize: code ke akhsar ka size.
      • wordWrap: lambi line screen se bahar na jaye.
      • formatOnSave: save karte hi code khud saaf ho jaye (Prettier ke sath).
      • autoSave: file khud save hoti rahe.

      formatOnSave ke liye Prettier extension install honi chahiye, aur settings mein usay default formatter chunna hoga.

      VS Code Ka Terminal

      Terminal mein hum text commands likh kar computer se kaam karwate hain. VS Code ke andar hi terminal hota hai, Ctrl + ` dabane se khulta hai. Aur ye hamesha usi folder mein khulta hai jo tumne VS Code mein open kiya ho.

      Basic Commands

      TERMINAL 
      cd my-website        # folder ke andar jana
cd ..                # ek folder peeche aana
mkdir images         # naya folder banana
code .               # current folder ko VS Code mein kholna
clear                # terminal saaf karna

      Files ki list dekhne ke liye Windows (Command Prompt) mein dir aur Mac/Linux mein ls chalao. Agle modules mein hum isi terminal se Git bhi use karenge.

      Pehla Project Banao

      1. Apne computer par ek naya folder banao, jaise my-first-website.
      2. VS Code mein File → Open Folder se wo folder kholo.
      3. Explorer mein New File dabao aur naam likho index.html.
      4. File mein ! likho aur Tab dabao, HTML ka basic structure khud ban jayega.
      5. Body ke andar ek heading likho aur save karo.
      6. File par right-click karo aur Open with Live Server chuno.

      Tumhara code kuch aisa dikhna chahiye:

      HTML 
      <!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Website</title>
</head>
<body>
    <h1>Hello, Developer!</h1>
</body>
</html>

      Browser mein tumhara page khul jayega. Ab heading ka text badal kar save karo, page khud update ho jayega.

      Is Module Ka Khulasa

      • VS Code ek free aur mashhoor code editor hai.
      • Install karte waqt "Open with Code" aur "Add to PATH" tick karo.
      • Live Server aur Prettier shuru ke liye behtareen extensions hain.
      • Settings se font, auto save aur formatting apni pasand ki bana sakte ho.
      • Terminal VS Code ke andar hi hota hai, Ctrl + ` se khulta hai.
      PRACTICE

      Naya folder bana kar uske andar index.html banao, apna naam heading mein likho aur Live Server se browser mein dekho. Agla module HTML ka hai, jahan hum asli website banana shuru karenge.
